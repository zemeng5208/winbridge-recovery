## 测绘记录

事实：视频元素取证区域约为 `812 × 469 px`。画面内单条胶囊约为 `288 × 66 px`，宽高比约 `4.36:1`，端部半径约 `33 px`。

| 特征 | 观察值 / 行为 |
|---|---|
| 轨道 | 近黑胶囊，右侧未完成区保持稳定；没有从左向右漂移粒子 |
| 进度坐标 | 不规则前沿中心与百分比位置基本一致 |
| 前沿核心 | 约 8–12 px，近似纵向，有 3–5 个较大的凸凹瓣 |
| 尾雾 | 前沿后方约 28–45 px，柔软且受胶囊裁切 |
| 边缘 | 最前端亮边较硬，主体与尾雾逐层变软 |
| 三色 | 上条橙/红/洋红，中条青/白/蓝，下条薄荷/白/紫；不同条强调不同通道 |
| 文本 | 左侧标签和右侧大百分比固定覆盖，不随前沿移动或形变 |
| 节奏 | 前沿平滑移动，凸凹瓣在相邻帧中挤压与回弹；没有跳帧式扫光 |
| 背景对比 | 流体主体只在前沿附近获得高亮，已完成区仍接近黑色 |

## 本地代码映射

- `src/components/FluidProgress.jsx`：稳定文字层、进度坐标和三色变量。
- `src/styles.css`：暗胶囊、轻度着色的已完成区、两层尾雾、前沿阴影、主体、亮边和热点。
- 主组件上限 `340 × 78 px`，比例约 `4.36:1`；对照组件上限 `300 × 68 px`，比例约 `4.41:1`。
- 前沿只在 `--fluid-progress` 坐标附近形变，不使用普通渐变扫光、粒子流或波浪线。
- 88% 后用 `--fluid-compression` 压缩横向体积，文字层保持不动。

## 降级

- `prefers-reduced-motion` 或“减少动态”：冻结前沿和尾雾动画，保留静态不规则亮边。
- 低端设备模式：移除尾雾、阴影、动态主体和热点，保留单层静态边界。
- 系统主题：只调整轨道和文字对比，不改变百分比坐标、三态或颜色通道。
- DPI：用弹性宽度、固定比例和独立文字层，避免滤镜改变文本清晰度。

## 内部代码帧与判断

默认三色本地帧位于：

- `research/internal/local-frames/local-default-fluid-motion-a.png`
- `research/internal/local-frames/local-default-fluid-motion-b.png`

内部并排页：`research/internal/fluid-compare.html`。

事实：相邻本地帧能看到同一进度坐标上的凸凹轮廓变化，文字与百分比保持稳定。

推断：用分层前沿而不是整段渐变，可以在未知原技术栈的情况下较接近目标的视觉重量和运动逻辑。

建议：总控后续视觉验收仍应在真实显示比例、125%/150% DPI、减少动态和低端模式分别观察；本文件不构成最终视觉验收。
