# 五套方案、保留项与上游约束

## 五套壳层

| 方案 | 视觉方向 | 主要差异 | 共享核心 |
|---|---|---|---|
| A 云母指挥舱 | Windows 11 云母、青蓝状态光 | 平衡密度、柔和几何 | 全部保留项、统一阶段环、统一流体组件 |
| B 碳黑作业台 | 碳黑平面控制台、琥珀风险、绿色完成 | 紧凑密度、方正控件 | 同上 |
| C 深海观测站 | 深海蓝玻璃层次 | 空间感与玻璃层最强 | 同上 |
| D 瓷白仪表盘 | 明亮技术文档、海军蓝结构 | 日间阅读与舒展密度 | 同上 |
| E 信号工作室 | 暖石墨、钴蓝/洋红/薄荷 | 色彩辨识度最高 | 同上 |

五套只改变主题变量、密度、几何和三色默认值；不删除、隐藏、合并或改入口。

## A 类产品协议

- 状态接口固定为 `Diagnosing → ReportReady → AwaitingDecision → Repairing → ResultReady`。
- 启动先只读诊断，报告展示 code、证据、影响、拟动作、风险、写入范围、可跳过性。
- 报告后等待用户选择；概念按钮只演示状态，不连接真实写入。
- 修复后停留结果页；展示诊断前后、问题、动作、结果、未解决项和日志入口。
- “修复完成后自动关闭”默认 `false`，迁移不得自动开启；所有新增布尔设置默认关闭。
- 小游戏仍是单一齿轮菜单入口，打开同一选择窗口并列 Snake 与 Minesweeper。

## Issues / 性能上游约束采用

| 上游结论 | 界面落点 | 概念实现 |
|---|---|---|
| `DiagnoseOnly → ShowReport → AwaitDecision` | 主窗口状态接口、只读诊断、修复说明 | 报告完成停在 `AwaitingDecision`，不自动写入 |
| 修复前七字段 | 修复说明对话框 | 七项逐行展示，不以总风险分替代 |
| 修复后停留结果页 | `ResultReady` 结果页 | 不自动退出；默认自动关闭为 OFF |
| 设置首帧立即显示 | 设置标题栏与插件页 | 窗口先显示，900 ms 后只读能力状态更新；不做真实网络探测 |
| UI 日志有界与批渲染 | 中央实时终端 | 80 行语义、筛选、暂停跟随、批次提示；完整日志仍在文件 |
| 只读状态进度 | 1–5 阶段和主流体条 | 只表达诊断/报告准备，不隐式承诺写入完成 |

冻结项：新插件写入、注册、备份、更新逻辑；磁盘日志协议；设置持久化写入时序；真实修复和最终核验。
