# WinBridge Recovery 4.0 original menu icon system

- Grid: 24 by 24 units. Menu strokes use 1.8-unit rounded geometry; the gear uses eight equal teeth around the exact (12, 12) center.
- Scope: games, theme, observe, and settings menu entries only. The WinBridge product brand mark is intentionally unchanged in this stage.
- Small sizes: the same menu masters are rendered at 16, 20, 24, 32, and 48 CSS pixels without optical offsets.
- Brand boundary: these paths were constructed for the WinBridge menu. They do not use OpenAI path data, proportions, or assets.
- Distribution: project-original SVG assets; no third-party icon path is embedded.
